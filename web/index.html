YouTube Shorts (Google Cloud OAuth 2.0)

Autenticação oficial do Google para publicação automática no seu canal

⚪ Não Configurado

Como obter seu arquivo client_secrets.json (gratuito em 3 minutos):

  1. Acesse o Google Cloud Console e crie um projeto (ex: Cortes AI Studio).
  2. No menu de busca ou em APIs e Serviços > Biblioteca, pesquise por YouTube Data API v3 e clique em Ativar.
  3. Em Tela de Consentimento OAuth: escolha Externo, preencha o nome do app e adicione o seu e-mail do YouTube em Usuários de Teste.
  4. Em Credenciais, clique em + Criar Credenciais > ID do Cliente OAuth (Tipo de Aplicativo: Aplicativo para Computador / Desktop App).
  5. Clique na setinha de Download JSON da credencial criada.
